### 周报 (report)

**Summarize the user's work over a period from Git.** Use the plugin's
`report` skill as is (it is a separate skill so it can be called directly as
`dflow:report`). Inside a dflow session, read `../report/SKILL.md` and follow it, then run the
finished text through `references/unslop.md` and `scripts/slop-check.sh -`.
Read-only: it writes no file unless the user asks.
