# 通用解 (general fix)

A fix or design must hold beyond the one case in front of you.

- Say explicitly which other inputs, projects, engines, or users it covers, and
  check at least one besides the reported case when that is cheap.
- No hard-coded names, IDs, paths, or magic values for one instance; no
  intrusion into user content (generated games, user files) to make one case
  pass.
- If only a special-case fix is possible now, label it as such and name what
  the general fix would need.

You skipped this when the user has to ask "这个方案是通用的么".
