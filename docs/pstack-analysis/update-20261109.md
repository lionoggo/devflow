## 采纳

1. **审查结论要有证明，并加上阻塞规则**：
   - `SKILL.md` 新增 **Findings need proof**；
   - `playbooks/review.md` 的分桶改为 必须改 / 值得考虑 / 未证实 / 不采纳；
   - 以下地方引用同一条规则：`playbooks/unattended.md` Close 第 6、7、9 步，`playbooks/verify.md` 第 6 步，`references/plan-review.md`。
   
   审查方在只读沙箱里，跑不了命令，所以由主会话在临时目录重跑它给出的命令。
2. **只改措辞的修复不复审**：`unattended.md` 第 8 步改为主会话自己对照代码重读改动的行，写一行 `side` 记录；`verify.md` 第 7 步同样只需重读。
3. **解释数字**：`principles/explain-number.md` 增加"先写决定和噪声底线"。
4. **无人值守中途的发现**：`unattended.md` Round 第 6 步只修目标需要的，其余转后续事项。
5. **复述目标**：
   - `principles/align-goal.md` 写明：给别的代理的说明，以及实施、验收、无人值守的最终回复，要复述目标；
   - 这三个流程的回复模板加"目标"一行；
   - 增加"证据推翻了要的改动，就停下"。
   
   按用户选择，日常回复不加。
6. **不改插件缓存**：`playbooks/tune.md` 第 4 步规定只改源仓库，改完提醒运行 `codex plugin add dflow@devflow`；别的插件先复制一份再改。
7. **模型被拒**：`SKILL.md` 和 `references/hosts.md` 规定，`-m` 指定的模型被拒时，用 Codex 默认模型再跑一次，并说明。
8. **slop-check 的行内代码**：
   - `scripts/slop-check.sh` 改为按"同样长度的反引号串"配对；
   - 新增 2 个正例、2 个反例；
   - 旧代码上，其中一个正例漏报、一个反例误报。
9. **多线精简**（用户决定这次就做，脚本不动）：
   - `playbooks/lines.md` 从 407 行减到 179 行，结构改成 Topology / Carriers / Supervision / Steps；

   - 逐条去向见文末对照表。

|---|---|---|---|

收尾在最终 HEAD 上逐条核对了清单的 3 条验收，账本两条线都是 pass，日志里有"来源 → 落地"的映射，worktree 和分支已清理。

试点暴露的问题和处理：

1. **单元表缺 `branch` 时 `land` 被拒**：第 3 步没写要填分支，主会话漏了。已在 `lines.md` 第 3 步写明。
