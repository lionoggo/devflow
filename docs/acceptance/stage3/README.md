验收中发现并修复的问题：
1. 收尾时数 DANGER 用了 grep，把自己的命令也算进去 → `timeline.py --danger`（e9f5aec）。
2. "按默认做"的依赖判断过严 → 不管选哪个选项代码都不变的单元，不算依赖（e9f5aec）。
3. 被杀会话的 `caffeinate` 接手时不会停 → `claim` 接手过期租约时停掉它（2317899）。
4. 时间线只取命令第一行，多行命令后面的 `git push` 会漏，后面几行的检查也看不到；开跑时创建运行分支被误报 → 扫描完整命令、显示时保留各行、放过 `dflow/` 分支的创建（0ef3987）。
5. 框定新增的检查脚本不在 Git 里，改了也查不出 → `start` 行记哈希，收尾核对（0ef3987）。

测试本身的两处偏差：tmux `-e` 没有把环境变量传给会话，`.zshenv` 也会把 Homebrew 放到 PATH 最前，所以 r3 想测的"codex 不可用"没测成，改在 r6 用 `env CODEX_HOME=` 完成。

没有覆盖的：
- 撤销"无进展的一轮"（小演示里每一轮都有进展）；
- 多小时运行、`/loop` 跨多次唤醒（演示都在一轮会话内跑完）；
- 通知推送到手机（Remote Control 没连，只发到终端）。
这些留给 E1，在 ludus 的真实任务中观察。
