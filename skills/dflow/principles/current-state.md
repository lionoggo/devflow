# 以现状为准 (current state over history)

- Docs, old plans, memory, and summaries describe the past. Check any claim
  you rely on against current code, config, or runtime before acting on it.
- Code does not prove its own intent: say why something exists only with a
  written source (commit, PR, ticket, comment, doc); otherwise label it 推测.
- Missing evidence: ask the user for it or say what you searched. Never fill
  the gap with a confident guess.

You skipped this when the user says "早就下线了" or "不要相信历史文档".
